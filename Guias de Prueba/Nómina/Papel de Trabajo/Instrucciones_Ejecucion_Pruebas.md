# 🚀 Instrucciones para Ejecutar Pruebas Automatizadas

Siga estos pasos para ejecutar la validación automática del Papel de Trabajo de Nómina.

## Pasos para ejecutar

1. Abra su ventana de consola (Terminal).
2. Ejecute el siguiente comando y presione **Enter**:
   ```bash
   node ejecutar_pruebas.js
   ```
3. Espere a que cargue el Gestor de Pruebas Automatizadas en la pantalla.
4. Busque la opción **Papel de Trabajo de Nómina** (o `workpaper_nomina.test.tsx`), escriba el número de la lista y presione **Enter**.
5. Deje que el programa haga las validaciones.

## Resultados
Al finalizar, se guardará automáticamente un reporte en formato CSV (Excel) en la carpeta de `Guias de Prueba`.
El nombre del archivo será similar a `Evidencia_Resultados_workpaper_nomina_2026-10-08.csv`.

Ábralo para verificar qué validaciones pasaron de manera correcta.
